      Questions, answered

      Everything you need to know about making icons with Pureico.

      Are my images uploaded anywhere?

      No. Pureico reads and converts your images inside your browser, in a background Web Worker. There is no server that could receive them, and the page’s Content Security Policy blocks it from sending data anywhere. It even works with your internet connection switched off.

      Which sizes should a favicon.ico include?

      For a website, 16, 32 and 48 px cover browser tabs, bookmarks and Windows shortcuts: that is the Favicon preset. Windows desktop apps also need a 256 px image, which the Desktop app preset adds. Pureico stores the small sizes as classic bitmaps so even old software can read them.

      How do I make an .icns file for a macOS app?

      Turn on macOS .icns. Pureico packs Apple’s full set, from 16 to 1024 px including Retina sizes, into one file you can use with tools such as electron-builder’s mac.icon setting or PyInstaller’s --icon option for PySide6 and PyQt apps. For the sharpest result, start from a 1024 px image or an SVG.

      Can Pureico round the corners of my icon?

      Yes. Under Corners, choose Rounded and drag the radius slider (50% makes a circle), or choose macOS for Apple’s app icon shape with its standard margin and a soft shadow. If your logo has a transparent background, turn on Background to place it on a solid tile and set the padding around it.

      Can I make icons for a Chrome or Firefox extension?

      Yes. Turn on Browser extension PNGs to get 16, 32, 48 and 128 px PNG files plus a Manifest V3 snippet whose paths match the files in your download.

      Why does my icon look blurry at 16 px?

      A 16 × 16 icon has only 256 pixels, so fine details and thin lines disappear. Simplify the artwork, use bold shapes and strong contrast, and check both the dark and light tab previews before you download.

      Can I convert several images at once?

      Yes. Drop up to 20 images and Pureico creates a single zip file with a folder for each one.
